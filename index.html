        Questions people ask
        
    
        
      
        
        Do these QR codes expire or stop working?
        
        No. Everything is stored inside the code itself, so it works forever. It doesn't depend on this website, and there's no subscription.
        
      
        
      
        
        Can I change a code after I've printed it?
        
        No. The content is part of the pattern, so new content means a new code. If you might change a link later, point the code to a page you control (like your website) and update that page instead.
        
      
        
      
        
        Is it really free and private?
        
        Yes. Your code is made right here in your browser. Nothing you type is sent to us or anyone else, and there's nothing to sign up for.
        
      
        
      
        
        How big should I print it?
        
        At least 2 × 2 cm (about 1 inch) for scanning up close. A simple rule: make it about one tenth of the scanning distance. So for a poster read from 2 metres away, print the code about 20 cm wide. Use the Large image size or SVG for printing.
        
      
        
      
        
        My code won't scan. What can I do?
        
        Use a dark code on a light background, keep the white border, and don't make the logo too big. The check under the preview tells you if something might be a problem. Also make sure the printed code isn't too small or shiny.
        
      
        
      
        
        How do people scan it?
        
        Most phones just need the camera app: point it at the code and tap the link or button that appears. Older phones may need a free QR scanner app.
        
      
        
      
        
        Which download should I pick?
        
        "Download image" (PNG) works everywhere: documents, websites, chats and most printing. SVG stays perfectly sharp at any size, which professional printers and designers prefer.
